# Contributing to prsplit

Thank you for contributing to `prsplit`.

## Development Setup

1. Fork this repository and clone your fork.
2. Install dependencies:

```bash
npm install
```

3. Build and test:

```bash
npm run build
npm test
```

## Branch and Commit Guidelines

- Create a focused branch for each change.
- Keep pull requests small and reviewable.
- Use clear commit messages that describe why the change is needed.

## Pull Request Checklist

- [ ] The change is scoped to a clear goal.
- [ ] `npm run build` succeeds.
- [ ] `npm test` succeeds.
- [ ] README and docs are updated when behavior changes.

## Reporting Issues

- Use GitHub Issues: https://github.com/kMJT000/prsplit/issues
- Include reproduction steps, expected behavior, and actual behavior.
